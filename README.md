# Make GTA 6 — Sol del Mar

[![Bounty](https://make.fun/badge/gta6-01.svg)](https://make.fun/bounty/gta6-01) [![Rank](https://make.fun/badge/gta6-01/pinrocks/vice-bay-engine/rank.svg)](https://make.fun/bounty/gta6-01) [![Reward](https://make.fun/badge/gta6-01/pinrocks/vice-bay-engine/reward.svg)](https://make.fun/bounty/gta6-01)

**Sol del Mar** is an original 3D sun-soaked coastal open-world crime game built from scratch with Three.js ES modules and procedural Web Audio, running 100% offline in desktop Chrome. Explore eight coastal districts on foot, by car, motorcycle, or speedboat, take on an 8-mission syndicate campaign from the Casa del Sol safehouse, fight with 5 weapon classes, evade 1–5 star Patrulla police cruisers and roadblocks, and save your campaign offline.

Built for [Make GTA 6](https://make.fun/bounty/gta6-01) on [make.fun](https://make.fun?ref=zc8m81ne) ($1,666 USDC).

## Run

```sh
node serve.ts
```

Build the `/output` submission dossier locally:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

Enter bounties like this on [make.fun](https://make.fun/r/zc8m81ne).
